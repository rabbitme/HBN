# Renormalized Connection
The implementation of Renormalized Connection (RC). 

Paper:
Renormalized Connection for Scale-Preferred Object Detection in Satellite Imagery.

Download at https://ieeexplore.ieee.org/document/10630868 or https://arxiv.org/pdf/2409.05624.

# Introduction
This is an open source object detection toolbox based on PyTorch and MMDetection, MMYOLO.

The main branch works with PyTorch 1.12, mmyolo 0.5.0, mmcv 2.0.0.
